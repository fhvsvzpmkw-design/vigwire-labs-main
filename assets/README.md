# VigWire Labs visual assets

The homepage mockup is the visual authority for the main-site build.

Asset folders:

- `reference/` — locked homepage design reference.
- `hero/` — locked VigWire Labs hero/title artwork.
- `characters/` — Terminal, Market Bottle, Pulpy!, and Pick Pickle.
- `products/` — VIGscope and TenPlay supporting artwork.
- `banners/` — wide promotional/footer artwork.

Only approved artwork belongs in these folders. Earlier generated experiments should remain outside the production asset set.
