# VigWire Labs visual assets

This directory contains approved production artwork used directly by the VigWire Labs corporate/main site, plus retained design references.

## Directory map

- `reference/` — historical/locked design references retained for comparison and provenance.
- `brand/` — VigWire Labs brand marks, icons, and related corporate identity assets.
- `hero/` — main VigWire Labs hero/title artwork.
- `characters/` — corporate-site character artwork such as Terminal, Market Bottle, Pulpy!, and Pick Pickle.
- `products/` — supporting product artwork shown on the corporate page.
- `product-badges/` — product title/badge graphics used by the main page.
- `banners/` — wide promotional and banner artwork.
- `hotline/` — corporate-page Hotline/share-control artwork only.
- `wicked-interactions/` — approved crew interaction artwork used by the main site.

## Asset ownership rule

Only assets used directly by the VigWire Labs corporate/main site belong here.

Application-specific assets stay with the application that owns the page. In particular:

- VIGscope owns VIGscope, 19th Hole, Hotline, Syndicate, and related page-specific/share graphics.
- TenPlay owns TenPlay page-specific/share graphics.

Do not turn this directory into a shared warehouse for assets belonging to other VigWire applications.

Only approved artwork belongs in the production asset set. Earlier generated experiments and unused drafts should remain outside production folders or be removed when no longer needed.
