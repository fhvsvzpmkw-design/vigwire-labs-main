## Status

This repository is the independent build and preview surface for the VigWire Labs main site.

No DNS, Cloudflare Worker, scheduler, report-link, API-route, asset-route, compact-link, or production-routing changes are authorized by this repository setup.

## Visual authority

The locked homepage mockup and approved character artwork stored under `assets/reference/` are the visual authority for implementation. Curated image assets are organized under `assets/hero/`, `assets/characters/`, `assets/products/`, and `assets/banners/`.
